# 多平台内容生产工作台 · v0.1.0

单人本地 Web 应用，服务 **AKA张猩猩** 单账号。三平台（抖音 / 小红书 / 公众号）同一选题下各出一份内容，覆盖从资料底座、大纲确认、成稿、四闸质检到 Obsidian 归档的完整流程。

---

## 一、快速开始

### 前置条件

- macOS 或 Linux（Node 24 推荐，≥ 18 可用）
- Node.js：<https://nodejs.org>
- 已经配置好的 Obsidian Vault（可选，归档时才需要）

### 启动（双击方式）

1. 首次运行：在终端里 `chmod +x start.command && ./start.command`
   （macOS 也可以右键 → 打开）
2. 之后双击 `start.command` 即可启动服务并自动打开浏览器 http://localhost:5178

### 启动（命令行方式）

```bash
npm install         # 首次安装依赖（约 1–2 分钟）
npm run build       # 构建前端（仅首次或前端改动后需要）
npm start           # 启动 → http://localhost:5178
```

开发模式（自动重启后端 + 热更新前端，不依赖已构建的 dist）：

```bash
npm run dev         # 后端 5178 + Vite 5179
```

### 首次打开后建议做的事

1. 进入 **设置** 页 → 确认 Obsidian 库路径正确（默认 `/Users/liz/Documents/Obsidian Vault`）
2. 确认敏感词库路径默认指向 `~/.workbuddy/skills/douyin-sensitive-check/data/sensitive_words.txt`（2653 词）
3. （可选）编辑规则、Prompt 模板，或导入候选选题

## 二、项目结构

```
内容工作台/
├── start.command        # 双击启动
├── package.json         # Node 依赖 + scripts
├── server/              # Fastify 后端
│   ├── index.js         # REST API 路由（约 900 行）
│   ├── db.js            # SQLite 建表 + DEFAULTS 配置
│   ├── seed.js          # 53 条规则 + 5 份 Prompt 种子
│   ├── parse.js         # 三平台文本解析 + 结构判定
│   ├── qc.js            # 四闸质检引擎（H/R/G/T/X/S/C/V…）
│   ├── prompts.js       # Prompt 模板渲染 + 变量替换
│   ├── archive.js       # Obsidian Markdown 写入 + 指纹校验
│   ├── parsers.js       # 网页抓取 / 文件解析（DOCX/PDF/TXT/MD）
│   ├── radar.js         # 选题池雷达导入
│   └── text.js          # 相似度 / 重合度 / 句段切分工具
├── web/
│   ├── src/
│   │   ├── api.js            # 封装 fetch + 常量
│   │   ├── components.jsx    # Modal/Toast/Pill/CopyBtn…
│   │   ├── App.jsx           # 侧边栏 + 导航
│   │   ├── styles.css        # 完整设计系统
│   │   └── pages/            # 9 个页面组件
│   └── dist/            # 构建产物（运行时托管）
└── data/                # SQLite + 上传/导出/备份
```

后端技术栈：Fastify 5 + better-sqlite3 11（预编译 WAL 模式）。
前端技术栈：React 18 + Vite 6（ESM，非打包式，gzip 约 70KB）。

运行时只绑定 `127.0.0.1`，监听 5178；不走公网，不走云数据库。AI 出稿 / 修复需在设置页自行配置 OpenAI 兼容的 LLM（Key 只存本地 data/，不入库）。

| Tab | 功能 |

## 四、四闸质检速查

```
闸① 结构  X1X5 H1-H5 R1-R5 R8-R10 G1-G4 T1-T2
闸② 去 AI 味 S1-S3 X2-X4
闸③ 转化收尾 C1-C4 T3 T13 G7
闸④ 红线     V1-V4 R11 X2 X3
```

- 结构未通过时，后三闸不跑（减少无效问题）
- T 系列规则按内容类型（教程/测评/观点）自动切换子集
- V1 直读 `~/.workbuddy/skills/douyin-sensitive-check/data/sensitive_words.txt`（2653 词），不写回词库本身
- V1 结果统一标 `needsReview: true`，即"必审不等于违规"，人工判定后可放行或阻断
- 投流（ad=1）时 C1/C2 不跑，改跑 C3（互动词即阻断）
- 商单（sponsor=1）时 C4 检查互动词是否附【客户要求·风险已报批】

### 抖音专属格式要求

```
## 分镜脚本        ← 元数据（账号/时长/封面文案/发布文案）
## 场次表          ← Markdown 表格（场次/镜头/时长/画面/口播/字幕/素材）
## 纯口播稿        ← 7 字/秒，180–300 秒（±10% 容差 = 1134–2310 字）
```

### 小红书专属格式要求

```
## 标题  ← 12–20 字，含利益点 / 身份标签 / 数字
## 正文  ← 300–800 字，前三行先给结论
## 配图建议 ← 3–9 张
## 话题标签 ← 3–6 个
```

### 公众号专属格式要求

```
## 标题
## 开篇
## 正文  ← 章节 = ### 小标题 + 内容（至少 3 章）
## 结尾
```

## 五、版本 / 回滚 / 指纹

- **版本只增不改**：每次点"保存新版本"或"回滚"都产生新版本号
- **回滚** = 把历史版本内容再存一次 + `origin='rollback'` + note 写明来源
- **归档指纹**同时写在两处：frontmatter `指纹:` 字段 + 正文前的 `<!-- 正文指纹: xxx -->` 注释
- 归档默认模式 `abort`：同文件正文指纹不变 → 跳过；变了 → 返回 409 给前端展示三选
- 另存时按序号递增（v1 → v1-2 → v1-3 …）

## 七、已知限制

### 质检不保证合规

- V1/V2/V3 只按你本地词表做提示，不识别所有违规内容，也不保证抖音/小红书/公众号的真实审核通过
- H1-H5/R1-R11/G1-G8 都是启发式，对创意写作 / 小众内容 / 非标准句式可能产生误报
- S2 模板化连接词密度阈值 `0.45` 是经验值，可在设置里调
- X3 真实性用正则匹配"亲测/实测/翻车/截图/我做了"等关键词，没有命中不代表真的没写真实体验

### 抖音词库

- 仅直读本地文件，不校验来源或做自动更新
- ASCII 短词（长度 < 4 字符）跳过，避免英文单词内部误命中（如 `pass` 里不含敏感词但仍被扫）
- 白名单逐词生效，是子字符串精确匹配；词库里"法轮"和"法轮佛"是两条独立词，需要各加一次白名单

### 生成模式

- 双模式并存：
  1. **提示词工作流**：复制 Prompt → 外部 AI → 回填，不需要任何 Key
  2. **AI 自动出稿**：设置页填 OpenAI 兼容的 `base_url / api_key / model`（预置火山方舟、DeepSeek、Kimi、通义），一键出大纲 / 出稿
- AI 自动修复（质检页 / 创作页）：
  - **定向修复**：只把质检点名的句子交给 AI 重写，按编号回填，正文其它部分不动
  - **多轮**：定向 → 复检 → 仍不通过则最后一轮整篇重写兜底；**阻断清零即停**（建议项不强求）
  - 结尾类规则（C1/C2）只替换最后一句，避免把整段一起换掉
  - 整体类规则（如 H2 字数）不是某一句，定向修不了，会提示改用手动编辑
  - 单轮最长 240 秒（思考型模型写长文需要），整篇兜底会更慢

### 抓取边界

- 登录态页面（飞书/Notion 私有库/微信公众号后台）会明确报 `need-login`，不尝试登录
- 反爬页面返回 `fetch failed` 或空正文，不做伪装 User-Agent / Selenium 级别兜底
- 文件解析：PDF 限 100 页，DOCX 限 20MB，图片只登记不 OCR

### 数据

- SQLite 单文件存储，WAL 模式，自动每日备份保留 7 份
- 应用 **是唯一真相源**，Obsidian 里的 Markdown 是成品副本；如果两边指纹不一致，Obsidian 以"手改版本"为准保留，应用以"待覆盖版本"为准拒绝归档
- 删除选题不会删 Obsidian 文件（只删 SQLite 索引）

### 不承担

- 不声称选题"当前很热"
- 不自动发布到任何平台
- 不编造真实体验、截图、翻车细节、具体数据
- 不写回旧的「抖音视频账号分析」库

## 八、运行中

启动后在浏览器打开 http://localhost:5178 即可。关闭浏览器不影响服务，关闭终端窗口或 Ctrl+C 即可停止。

需要同时开多个库或改端口：

```bash
PORT=5181 WORKBENCH_DATA=/path/to/other/data npm start
```
